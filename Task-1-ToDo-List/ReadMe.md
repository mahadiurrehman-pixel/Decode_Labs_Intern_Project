# To-Do List Application ✅

A console-based To-Do List Management System built using Python as part of the DecodeLabs Internship project.

## 📌 Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Search tasks
- Clear all tasks
- Input validation for user entries

## 🛠️ Technologies Used

- Python 3

## 🧠 Concepts Implemented

- Functions
- Lists
- Loops
- Conditional Statements
- Exception Handling
- List Methods
- List Comprehension
- User Input Handling
