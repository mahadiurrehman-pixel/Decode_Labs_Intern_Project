# 🧠 General Knowledge Quiz

A simple command-line **General Knowledge Quiz** built with Python.  
The program asks users three general knowledge questions, checks their answers, provides instant feedback, and displays the final score.

---

## ✨ Features

- 🎯 Interactive command-line quiz
- ✅ Instant feedback after each answer
- 📊 Final score calculation
- 🔤 Case-insensitive answer checking
- 🚀 Beginner-friendly Python project
- 📦 No external libraries required

## ⚙️ How It Works

1. Displays a welcome message.
2. Prompts the user to answer three questions.
3. Converts answers to lowercase for case-insensitive comparison.
4. Checks each answer against the correct one.
5. Displays immediate feedback.
6. Calculates and shows the final score.
